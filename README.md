# Structured Programming Language (SPL)

Welcome to my **Structured Programming Language (SPL)** repository! 

This repository contains my C programming codes, course materials, lab assignments, and practice problems. It is organized to support my learning journey and help me revise important programming concepts throughout my academic studies.

## Programming Language

- **Language:** C
- **IDE:** Code::Blocks
- **Compiler:** GCC (GNU Compiler Collection)

## Purpose

The main purpose of this repository is to:

- Organize all my SPL course codes and learning materials in one place.
- Build a strong foundation in C programming.
- Practice problem-solving and logical thinking.
- Keep track of my learning progress throughout the course.
- Maintain a useful collection of codes for future revision and reference.

## Topics Covered

- Basic Programs
- Loops

- Arrays

- File Handling
- Lab Assignments
- Practice Problems

## Development Environment

All programs in this repository are written in C and developed using **Code::Blocks IDE**.

To run these programs, you can install Code::Blocks with a supported GCC compiler.

## How to Use This Repository

1. Clone or download this repository.
2. Open Code::Blocks IDE.
3. Create a new C project or open a C source file.
4. Copy or open the desired program.
5. Build and run the program to see the output.
6. Modify the code and practice different inputs to improve your understanding.
