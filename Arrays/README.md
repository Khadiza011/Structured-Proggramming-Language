# Arrays 

## Introduction

An array is a collection of multiple values of the same data type stored under one variable name.

Each value inside an array is called an element.

Array indexing starts from `0`.

### Example

```text
Values:  10  20  30  40  50
Index:    0   1   2   3   4
```

## 1D Array

A one-dimensional array stores elements in a single row.

### Example

```text
Marks = [75, 80, 65, 90, 85]
```

Here, the array contains five student marks.

### Uses

* Storing student marks
* Storing ages
* Storing prices
* Storing temperatures

---

## 2D Array

A two-dimensional array stores elements in rows and columns.

It is commonly used to represent a matrix or table.

### Example

```text
1  2  3
4  5  6
```

This matrix contains:

* `2` rows
* `3` columns

### Uses

* Matrix representation
* Student result tables
* Game boards
* Seating arrangements

---

## Array Traversal

Array traversal means visiting every element of an array one by one.

### Example

```text
Array = [5, 10, 15, 20]
```

Traversal order:

```text
5 → 10 → 15 → 20
```

Array traversal is used for displaying, searching, counting, and modifying elements.

---

## Matrix Operations

Matrix operations are performed using two-dimensional arrays.

### Common Matrix Operations

* Matrix addition
* Matrix subtraction
* Matrix multiplication
* Matrix transpose

---

## Advantages of Arrays

* Stores multiple values under one variable name
* Makes data management easier
* Allows fast access using indexes
* Useful for searching and sorting
* Useful for matrix operations
* Reduces the need for many separate variables

---

## Limitations of Arrays

* Array size is usually fixed
* It stores only one type of data
* Inserting or deleting elements can be difficult
* Accessing an invalid index may cause errors

---

## Applications of Arrays

* Student result management
* Product price storage
* Employee salary records
* Matrix calculations
* Image representation
* Searching and sorting
* Game development
* Data analysis

---

## Conclusion

Arrays are one of the most important concepts in programming.

A one-dimensional array stores data in a single row, while a two-dimensional array stores data in rows and columns.

Arrays are commonly used for traversal, calculating sums, finding maximum and minimum values, and performing matrix operations.
