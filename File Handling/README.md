
# File Handling in C

This folder contains beginner-friendly C programs
for understanding file handling.

## Topics Covered

- fopen() - Opening a file
- fclose() - Closing a file
- fprintf() - Writing formatted data
- fscanf() - Reading formatted data
- fgets() - Reading a line of text
- fputs() - Writing a string
- File Reading
- File Writing

## File Opening Modes

| Mode | Description |
|------|-------------|
| r    | Opens a file for reading |
| w    | Opens a file for writing |
| a    | Opens a file for appending |
| r+   | Opens a file for reading and writing |
| w+   | Opens a file for reading and writing |
| a+   | Opens a file for reading and appending |

## How to Compile and Run

Compile a program using GCC:

```bash
gcc fopen.c -o fopen
```

Run the program:

```bash
./fopen
```

For Windows:

```bash
gcc fopen.c -o fopen.exe
fopen.exe
```

## Requirements

- Basic knowledge of C programming
- A C compiler such as GCC

## Learning Goal

The goal of these programs is to understand
how to create, open, read, write, and close
files using the C programming language.
